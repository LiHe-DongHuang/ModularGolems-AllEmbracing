# ModularGolems-AllEmbracing
Requires ModularGolems: MassiveStorageUpgrade version 1.0.1 or higher. This module modifies the pickup upgrade kit functionality in ModularGolems to align with the Golem's storage capacity. When a Golem defeats a mob, loot is now prioritized for the Golem's internal storage; if full, it reverts to original logic.
